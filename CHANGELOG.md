# Change Log
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## [4.0.0] - 2026-09-29
### Added
- Support for PHPUnit 13.0
- Added Larastan
- Added Rector
- Added Pint

### Updated
- Dropped support for PHP versions below 8.4
- Dropped support for Laravel 11
- Removed PHP-CS-Fixer (replaced by Pint)
- Unsupported translation file extensions now throw an `InvalidArgumentException` instead of an `UnhandledMatchError`

## [3.1.0] - 2026-06-23
### Added
- Support for Laravel 13.0

## [3.0.0] - 2025-04-09
### Added
- Support for Laravel 12.0

## [2.0.0] - 2024-11-27
### Added
- Support for Laravel 11.0
- Added Codecov

### Updated
- Dropped support for anything before PHP 8.2
- Dropped support for Laravel 10 and below

## [1.0.0] - 2023-05-04
- Initial version.
